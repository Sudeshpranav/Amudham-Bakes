# Amudham Bakes (அமுதம் பேக்ஸ்) — Chennai Bakery & Confectionery

A modern, responsive, bilingual (English & தமிழ்) neighbourhood bakery web application built for **Amudham Bakes**, Mylapore, Chennai. Features fresh cakes, flaky masala puffs, butter biscuits, traditional sweets, and direct WhatsApp ordering.

---

## 🎂 Key Features

- **🍰 Interactive Menu & Showcase**: Categorized menu for Celebration Cakes, Savouries, Tea-Time Biscuits, and Festive Sweets.
- **🌐 Instant Bilingual Toggle**: English and தமிழ் language support across all menu items and descriptions.
- **📱 WhatsApp Direct Ordering**: Add items to your order note and launch WhatsApp with one tap (`+91 8838340480`).
- **📍 Location & Store Hours**: Mylapore, Chennai store hours, directions, and contact information.
- **⚡ Built with React 19 + Tailwind CSS + Vite**: Ultra-fast performance, smooth animations, and mobile-optimized responsiveness.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Motion
- **Bundler**: Vite 8

---

## 🚀 Development & Build

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
